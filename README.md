Deskripsi Singkat
Aplikasi ini merupakan sistem manajemen perkuliahan sederhana berbasis web.

Fitur utamanya:
Mahasiswa dapat melakukan enroll ke dalam mata kuliah dengan validasi (tidak bisa double enroll).
Admin dapat membuat data mahasiswa dan mata kuliah baru dengan validasi input.
Seluruh interaksi berbasis JavaScript DOM tanpa refresh halaman.

Fitur Utama
Enroll Course: Mahasiswa hanya bisa daftar sekali untuk tiap mata kuliah.
Manajemen Data: Admin dapat menambah mahasiswa & mata kuliah.
Validasi Form: Terdapat error message dan border merah jika input tidak valid.
Konfirmasi Hapus: Sebelum menghapus data, muncul dialog konfirmasi.
UI Dinamis: Menu aktif ditandai saat dipilih.
